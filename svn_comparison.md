# Git и SVN: сравнение

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?
В Git ветка — это лёгкий указатель на коммит, поэтому создание и переключение веток выполняется быстро и локально. В SVN ветвление исторически связано с копированием каталогов в централизованном репозитории и сильнее зависит от сервера.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?
Обычный коммит в SVN без доступа к центральному серверу сделать нельзя, потому что SVN использует централизованную модель: новая ревизия создаётся на сервере. В Git локальные коммиты возможны офлайн, а отправить их на сервер можно позже.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
SVN может оставаться удобным в legacy-проектах и организациях с уже выстроенной централизованной инфраструктурой, особенно когда важны централизованный контроль, привычные процессы и нет необходимости в распределённой работе.
