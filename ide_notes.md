# Git в VS Code: заметки

## Что удобно в VS Code
1. Панель Source Control наглядно показывает изменённые и подготовленные к коммиту файлы.
2. Встроенный diff удобно подсвечивает добавленные и удалённые строки.
3. История и расширение GitLens помогают быстро понять, кто и когда изменял строки файла.

## Что удобнее делать в терминале
Сложные операции с историей, например interactive rebase, удобнее и понятнее выполнять командами Git в терминале.
